# Photography

`campfire-1800.webp` and `campfire-900.webp` are resized WebP copies of a real photograph by Patrick Hendry, published November 11, 2017. The source identifies the camera as a Canon EOS 5DS. No generative image tools were used to create or alter these assets.

- Source: https://unsplash.com/photos/bonfire-in-the-middle-of-forest-during-night-time-kSj_xTPMrx4
- Image: https://images.unsplash.com/photo-1510374629110-439facca79ba
- License: https://unsplash.com/license
- Usage: homepage hero. Source and license attribution are retained in this file; no visible footer credit is displayed.
- Processing: proportional resizing and WebP encoding. The page uses CSS overlays for text contrast.
